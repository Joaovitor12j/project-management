# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

"Helper" — a project/ticket management app (Kanban, Scrum, road map, timesheets, Jira import) built on **Laravel 9 + Filament v2 + Livewire v2**, PHP 8.0+, MySQL. Almost all UI is the Filament admin panel; there is no separate front-end app.

## Commands

```bash
composer install-project        # full bootstrap: npm/composer install, build, .env, key, migrate, seed
php artisan migrate && php artisan db:seed   # seeds referentials, permissions, default role and default user
php artisan serve
php artisan queue:work          # required: notifications/emails and Jira imports are queued
npm run dev                     # Vite dev server; `npm run build` for production assets
php artisan optimize:clear      # clear caches after config/env changes

php artisan test                              # PHPUnit (Unit + Feature suites)
php artisan test --filter=SomeTest            # single test / method
./vendor/bin/pint                             # code style (Laravel Pint)

php artisan make:lang fr,de     # generate + Google-translate lang/<locale>.json files
php artisan trans:missing fr    # fill keys missing in other locales, using lang/fr.json as the key base
```

Default seeded login: `john.doe@helper.app` / `Passw@rd` (has all permissions). Docker: `docker-compose.yml` + `run.sh` (container entrypoint runs queue worker, migrate, seed, build, serve on :8000).

The test suite is only Laravel's example tests; DB env vars in `phpunit.xml` are commented out, so tests use the `.env` database.

## Architecture

- **Filament is the app.** Screens live in `app/Filament/Resources/*Resource.php` (CRUD, with `Pages/` subfolders) and `app/Filament/Pages/` (custom pages: `Kanban`, `Scrum`, `Board`, `RoadMap`, `JiraImport`, `Timesheet*`, `ManageGeneralSettings`). Dashboard widgets are in `app/Filament/Widgets/`. Blade views for custom pages are under `resources/views/filament/` and `resources/views/partials/`.
- **Kanban and Scrum share logic** via the `App\Helpers\KanbanScrumHelper` trait (filters, status columns, record loading, drag-and-drop ordering). Project `type` decides kanban vs scrum; project `status_type` decides status source: `custom` → `TicketStatus` rows with that `project_id`, otherwise global statuses (`project_id IS NULL`).
- **Model lifecycle hooks carry business logic** (check `boot()` before changing persistence):
  - `Ticket`: generates `code` (`{project.ticket_prefix}-{n}`) and `order` on create; on status change writes `TicketActivity` and notifies watchers; syncs `epic_id` from the ticket's sprint.
  - `TicketStatus` / `TicketType` / `TicketPriority` / `ProjectStatus`: only one `is_default` row is kept (saving one as default unsets others).
- **Authorization**: spatie/laravel-permission with string permissions like `List tickets`, `View ticket`, `Create ticket`, generated by `PermissionsSeeder` from a module list × actions, plus extras (`Manage general settings`, `Import from Jira`, …). Policies in `app/Policies/` check those strings and, for projects/tickets, also membership (owner, responsible, or project user). When adding a module, add it to `PermissionsSeeder::$modules`, create a policy, and re-seed.
- **Runtime settings**: `App\Settings\GeneralSettings` (spatie/laravel-settings, migrations in `database/migrations/*general_settings*`). `AppServiceProvider::configureApp()` overrides config at boot (locale, app name, logo, registration, social login, login form, OIDC) from these settings — config values are not just `.env`.
- **Auth**: filament-breezy (login/profile/registration), filament-socialite (social login), custom OIDC controller (`app/Http/Controllers/Auth/OidcAuthController.php`, routes in `routes/web.php`). New users get a `creation_token` and validate via `/validate-account/{token}`.
- **Real-time & queues**: Pusher broadcasting; notifications (`app/Notifications`) and `ImportJiraTicketsJob` run on the queue. Jira API access is in `App\Helpers\JiraHelper`.
- **Attachments** use spatie media library (`Ticket implements HasMedia`); Excel exports via maatwebsite/excel in `app/Exports`.
- **Assets**: Vite builds `resources/css/filament.scss` and `resources/js/filament.js`, registered as the Filament theme/scripts in `AppServiceProvider`.

## Conventions

- All user-facing strings go through `__('...')`; translations are JSON files in `lang/` (~60 locales), machine-generated by the commands above — keys are the English strings themselves (there is no `lang/en.json`); use the commands above to propagate new keys instead of hand-editing every locale.
- Filament navigation groups are fixed in `AppServiceProvider`: `Management`, `Referential`, `Security`, `Settings`.
